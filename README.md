# 苏格拉底式启发教学 Agent

基于 Coze 搭建的多模态数学辅导 Agent。  
围绕数学解题场景，将题目检查、逻辑求解、学生状态识别、文本情绪识别和教学策略拆分为结构化节点，根据学生每一轮表现动态调整提示难度与回复方式。

> 项目关键词：AI Agent / Coze / 多模态输入 / Workflow / Structured Output / Prompt Engineering / 多轮对话

---

## 项目介绍

传统 AI 搜题场景中，模型容易在获取题目后直接输出完整答案，同时难以稳定判断学生当前卡在读题、理解、列式还是计算环节。

本项目围绕三个核心问题设计教学工作流：

- **答案展示时机**：控制最终答案和关键步骤在对话中的展示范围。
- **学生状态判断**：结合学生回答和标准解题步骤判断当前理解程度与卡点。
- **教学策略适配**：学生状态控制提示难度，文本情绪控制回复语气。

Agent 每轮基于完整解题路径、学生当前状态和上下文信息生成下一步教学动作，持续推进当前解题任务。
